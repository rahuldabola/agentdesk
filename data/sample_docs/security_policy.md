# Security Policy

## Data Retention

Customer data is retained for 90 days after account deletion, after which it is permanently
purged from all systems including backups.

## Access Control

Production database access requires a VPN connection plus hardware-key 2FA, and all access
is logged and reviewed weekly by the security team.

## Vulnerability Reporting

Security vulnerabilities should be reported to security@company.example. Critical
vulnerabilities are patched within 24 hours; medium/low severity within 30 days.
